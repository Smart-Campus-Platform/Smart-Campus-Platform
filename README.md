# 🎓 Smart Campus Platform

A full-stack web application designed to improve the management of a university campus resources by providing a centralized platform for reservations, mobility services, and campus administration.

Developed as an academic project in the 2nd Semester of the 2nd Year of our Bachelor in Computer Science, the platform combines backend development, database design, and web technologies to deliver a practical solution for managing campus facilities.

---

## 📖 Overview

Smart Campus Platform allows students and staff to access and manage different campus services through a single application.

The project focuses on creating a scalable and organized architecture while applying software engineering principles, database modeling, and RESTful application development.

## Getting Started

### Prerequisites

* Node.js
* MySQL
* Git

### Installation

Clone the repository

```bash
git clone https://github.com/your-username/smart-campus-platform.git
```

Install dependencies

```bash
npm install
```

Configure the database connection in the `.env` file.

Run the application

```bash
npm run dev
```

Open your browser and navigate to:

```text
http://localhost:3000
```
